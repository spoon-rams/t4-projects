Description:

The new Background Content Wrapper provides a flexible way to group and visually highlight other content types within a page. The wrapper allows content editors to place existing components over either a background image or a solid background color, creating distinct sections and adding greater visual variety to page layouts.

Content Type Features:

  • Custom image background.
  • Custom and optional background color.
  • Custom and optional font color
  • Custom overlay color input field
  • Optional overlay opacity settings

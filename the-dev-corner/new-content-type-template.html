Description:

The new Interactive Feature Cards component provides a visually engaging way to highlight and organize related content using background imagery, icons, headings, descriptive text, and calls-to-action. Each card initially displays key information in an easy-to-scan layout, while additional supporting text and an optional call-to-action are revealed when a visitor hovers over the card. This interaction keeps the layout visually focused while allowing visitors to explore more information as needed, giving content editors a flexible way to create interactive pathways to related content throughout the website.

Content Type Features:

  • Custom image background.
  • Custom and optional background color.
  • Custom and optional font color
  • Custom overlay color input field
  • Optional overlay opacity settings
